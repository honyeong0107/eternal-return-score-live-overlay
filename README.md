# 이터널 리턴 실시간 점수 오버레이 (Eternal Return Score Live Overlay)

이터널 리턴 대회 방송용 실시간 점수판입니다. 관전자 화면에서 8개 팀의 **KS·TS·생존 상태**를 읽고 OBS 점수판에 바로 반영합니다.

- 1920×1080 이터널 리턴 관전자 HUD 추적
- OBS용 800×600 투명 오버레이
- 최대 9라운드 누적 점수와 라운드별 수동 수정
- 전멸 감지와 `ELIMINATED` 애니메이션
- 대회별 팀명·색상 템플릿 저장
- GPU, CUDA, Tesseract 설치 불필요
- 저사양 PC를 위한 초당 1회 기본 인식

## 필요한 설치

복잡하게 따로 설치할 건 없습니다. 아래 두 가지만 있으면 됩니다.

1. **Windows PC**
2. **[Python 3](https://www.python.org/downloads/)**

방송에 사용할 때만 **[OBS Studio](https://obsproject.com/)**가 추가로 필요합니다. 이터널 리턴과 OBS는 따로 설치해야 합니다.

## 설치하고 실행하기

### 1. 프로그램 다운로드

GitHub 페이지 위쪽에서 **Code → Download ZIP**을 누릅니다. 받은 ZIP 파일은 마우스 오른쪽 버튼을 누른 다음 **모두 압축 풀기**로 풀어 주세요.

> ZIP 파일 안에서 바로 실행하지 말고 먼저 압축을 풀어 주세요.

### 2. Python 설치

[Python 다운로드 페이지](https://www.python.org/downloads/)에서 Python 3를 설치합니다. 설치 화면에 **Add Python to PATH**가 보이면 꼭 체크해 주세요.

Python을 새로 설치했다면 열려 있던 명령 프롬프트 창을 닫아 주세요.

### 3. 프로그램 실행

압축을 푼 폴더에서 **`start.bat`을 더블클릭**하면 됩니다.

처음 한 번은 필요한 파일을 자동으로 받습니다. 인터넷 속도에 따라 몇 분 정도 걸릴 수 있습니다. 설치가 끝나면 제어 화면이 브라우저에서 열립니다.

검은 명령 창은 방송이 끝날 때까지 열어 두면 됩니다. 창을 닫으면 프로그램도 같이 꺼지고 사용하던 포트도 바로 반납됩니다.

## 라이브 스코어 사용 방법

1. 이터널 리턴 관전자 화면을 **1920×1080**으로 설정합니다.
2. 제어 화면의 **게임 화면** 목록에서 이터널 리턴 창을 선택합니다.
3. 필요한 대회·라운드와 팀명을 설정합니다.
4. **라이브 스코어 시작**을 누릅니다.
5. 방송이 끝나면 **라이브 스코어 종료**를 누릅니다.

라이브 스코어를 종료해도 누적 점수는 그대로 남습니다. 다시 시작하면 기존 점수에서 이어집니다. 전부 지우고 새로 시작할 때만 **새 경기 초기화**를 누르면 됩니다.

팀명은 추적을 시작할 때 한 번 인식합니다. 인식된 이름이나 점수가 다르면 제어 화면에서 즉시 직접 수정할 수 있습니다.

## OBS에 점수판 넣기

1. 먼저 `start.bat`으로 프로그램을 실행합니다.
2. OBS의 **소스 목록 → + → 브라우저**를 선택합니다.
3. 아래 값을 입력합니다.

| 항목 | 값 |
| --- | --- |
| URL | `http://127.0.0.1:8765/overlay` |
| 너비 | `800` |
| 높이 | `600` |
| 사용자 지정 FPS | `2` |

아무것도 안 보이면 일반 브라우저에서 <http://127.0.0.1:8765/overlay>를 먼저 열어 보세요. 이 주소도 안 열리면 `start.bat` 명령 창이 실행 중인지 확인하면 됩니다.

## 대회와 라운드 관리

제어 화면에서 다음 항목을 대회별로 저장할 수 있습니다.

- 대회 이름과 전체 라운드 수(1~9)
- 8개 팀 이름
- 점수판 제목
- 파스텔 핑크·브라운·그린·블루·레드 템플릿
- `+` 버튼으로 여는 텍스트·KS·순위·전멸 효과 세부 색상

미리보기 아래에서 종료된 라운드를 선택해 팀별 KS·TS·패널티를 수정할 수 있습니다. 패널티는 총 TS에 반영되지만 OBS 리더보드에 별도 열로 표시되지는 않습니다.

TS가 같으면 KS가 높은 팀이 위에 표시됩니다. KS도 같으면 해당 라운드에서 더 오래 생존한 팀이 위에 표시됩니다.

## 전멸 판정

- 선수 초상화의 사망·다운 상태를 개별 판정합니다.
- 초상화에 부활 시간초가 있으면 부활 대기 상태로 처리합니다.
- 1일차 전원 사망은 `BREAK` 상태로 유지합니다.
- 2일차 이후 생존자가 0명이고 부활 시간초도 없을 때 `ELIMINATED`로 확정합니다.
- 전멸 상태는 해당 라운드가 끝날 때까지 유지됩니다.

## 잘 안 될 때

### `Python을 찾을 수 없습니다`가 나오는 경우

Python 3를 다시 설치하면서 **Add Python to PATH**를 체크해 주세요. 설치가 끝나면 `start.bat`을 다시 실행하면 됩니다.

### 처음 실행이 오래 걸리는 경우

첫 실행에만 필요한 Python 파일을 받습니다. 인터넷 연결을 확인하고 검은 창을 닫지 않은 채 기다려 주세요.

### OBS에서 오버레이가 비어 있는 경우

- `start.bat` 명령 창이 열려 있는지 확인합니다.
- 브라우저 소스 URL이 `http://127.0.0.1:8765/overlay`인지 확인합니다.
- 브라우저 소스 크기를 **800×600**으로 맞춥니다.
- OBS 브라우저 소스를 새로고침합니다.

### 게임 화면을 찾지 못하는 경우

- 이터널 리턴을 먼저 실행한 뒤 제어 화면을 새로고침합니다.
- 게임을 창 모드 또는 테두리 없는 창 모드로 실행합니다.
- 게임 해상도와 관전자 HUD가 1920×1080인지 확인합니다.

## 설정과 개인정보

프로그램은 `127.0.0.1`에서만 돌아갑니다. 게임 화면이나 점수를 외부 서버로 보내지 않습니다. 대회 설정과 점수는 프로그램 폴더의 `config.json`에 저장됩니다.

프로그램을 삭제하려면 실행 중인 명령 창을 닫고 폴더 전체를 삭제하면 됩니다. 설정을 보관하려면 삭제 전에 `config.json`을 따로 복사하세요.

## 현재 인식 범위

현재는 1920×1080 이터널 리턴 관전자 HUD를 기준으로 맞춰 놨습니다. 게임 업데이트로 HUD 위치나 배율이 바뀌면 인식 좌표나 숫자 템플릿도 다시 맞춰야 할 수 있습니다.

이 프로젝트는 비공식 커뮤니티 도구이며 Nimble Neuron 및 게임 공식 운영사와 제휴하거나 보증받지 않았습니다.
