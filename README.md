# 이터널 리턴 실시간 점수 오버레이 (Eternal Return Score Live Overlay)

이터널 리턴 대회 방송용 실시간 점수판입니다. 관전자 화면에서 8개 팀의 KS·TS·생존 상태를 읽고 OBS 점수판에 바로 반영합니다.

- 1920×1080 이터널 리턴 관전자 HUD 추적
- OBS용 800×600 투명 오버레이
- 최대 9라운드 누적 점수와 라운드별 수동 수정
- 전멸 감지와 `ELIMINATED` 애니메이션
- 대회별 팀명·색상 템플릿 저장
- GPU, CUDA, Tesseract 설치 불필요
- 초당 5회 기본 인식 (저사양 PC는 3회 권장)

## 설치 전에 확인해 주세요

- Windows 10 또는 Windows 11에서 사용합니다.
- Python 3.10 이상이 필요합니다. 설치 여부와 버전은 `start.bat`이 확인합니다.
- 처음 실행할 때 필요한 구성 요소를 내려받으므로 인터넷 연결이 필요합니다.
- 방송에 사용할 때만 [OBS Studio](https://obsproject.com/)가 추가로 필요합니다. 이터널 리턴과 OBS는 별도로 설치해야 합니다.

Microsoft Defender 오탐 문제로 EXE 파일은 제공하지 않습니다. 예전에 받은 EXE가 격리되었다면 복원하거나 Defender 예외로 등록하지 말고, 아래의 `start.bat` 실행 방법을 사용해 주세요.

## 처음 설치하기

### 1. 프로그램 ZIP 받기

1. 이 GitHub 페이지 위쪽의 초록색 `Code` 버튼을 누릅니다.
2. 메뉴에서 `Download ZIP`을 누릅니다.
3. 다운로드가 끝나면 브라우저의 다운로드 목록이나 Windows의 `다운로드` 폴더에서 ZIP 파일을 찾습니다.

### 2. ZIP 압축 풀기

1. 받은 ZIP 파일을 마우스 오른쪽 버튼으로 누릅니다.
2. `모두 압축 풀기`를 선택합니다.
3. 압축을 풀 위치를 정하고 `압축 풀기`를 누릅니다.
4. 새로 만들어진 폴더를 엽니다.

> ZIP 파일 안에서 `start.bat`을 바로 실행하면 정상적으로 설치되지 않습니다. 반드시 압축을 먼저 풀어 주세요.

### 3. Python 준비하기

1. 압축을 푼 폴더에서 `start.bat`을 더블클릭합니다.
2. Python 3.10 이상이 이미 설치되어 있으면 다음 단계가 자동으로 진행됩니다.
3. Python이 없거나 버전이 낮으면 검은 창에 안내가 나오고 [Python 공식 Windows 다운로드 페이지](https://www.python.org/downloads/windows/)가 열립니다.
4. 공식 설치 프로그램에서 Python 3를 설치합니다. `Add python.exe to PATH` 항목이 보이면 체크해 주세요.
5. 설치가 끝나면 기존 검은 창을 닫고 `start.bat`을 다시 더블클릭합니다.

### 4. 처음 한 번만 필요한 설치 기다리기

1. `처음 실행 준비 중입니다`라는 메시지가 나오면 창을 닫지 말고 기다립니다.
2. 프로그램 전용 Python 환경과 화면 인식 구성 요소가 자동으로 설치됩니다.
3. 컴퓨터와 인터넷 속도에 따라 몇 분 정도 걸릴 수 있습니다.
4. `준비가 끝났습니다`라는 메시지가 나온 뒤 제어 화면이 기본 브라우저에서 열립니다.

설치 중 오류가 나오면 검은 창이 그대로 멈춥니다. 오류 문구를 확인한 뒤 인터넷 연결을 점검하고 `start.bat`을 다시 실행해 주세요.

## 다음부터 실행하기

1. 압축을 풀어 둔 프로그램 폴더를 엽니다.
2. `start.bat`을 더블클릭합니다.
3. 제어 화면이 브라우저에서 열릴 때까지 기다립니다.
4. 방송이 끝날 때까지 검은 명령 창을 열어 둡니다.

프로그램을 종료하려면 검은 명령 창을 닫습니다. 프로그램과 로컬 서버가 함께 종료되고 사용하던 포트도 바로 반납됩니다.

## 라이브 스코어 사용 방법

1. 이터널 리턴 관전자 화면을 1920×1080으로 설정합니다.
2. 제어 화면의 게임 화면 목록에서 이터널 리턴 창을 선택합니다.
3. 필요한 대회와 팀명을 설정합니다.
4. 라운드가 시작되면 `N라운드 라이브 스코어 시작`을 누릅니다.
5. 라운드가 끝나면 `N라운드 라이브 스코어 종료`를 누릅니다.

라이브 스코어를 종료하면 현재 라운드 점수가 확정되고 다음 라운드로 넘어갑니다. 잘못 종료했다면 시작 버튼 옆의 라이브 종료 되돌리기를 누르면 됩니다. 다음 라운드에서 라이브 스코어 시작을 누르면 누적 점수에 새 라운드 점수가 이어집니다. 전부 지우고 새로 시작할 때만 새 경기 초기화를 누르면 됩니다.

팀명은 추적을 시작할 때 한 번 인식합니다. 인식된 이름이나 점수가 다르면 제어 화면에서 즉시 직접 수정할 수 있습니다. 새 경기 초기화를 누르면 현재 인식된 팀명은 사라지고 대회 설정에 저장된 팀명으로 돌아갑니다.

## OBS에 점수판 넣기

1. 먼저 `start.bat`으로 프로그램을 실행합니다.
2. OBS의 소스 목록 → + → 브라우저를 선택합니다.
3. 아래 값을 입력합니다.

| 항목 | 값 |
| --- | --- |
| URL | `http://127.0.0.1:8765/overlay` |
| 너비 | `800` |
| 높이 | `600` |
| 사용자 지정 FPS | `2` |

아무것도 안 보이면 일반 브라우저에서 <http://127.0.0.1:8765/overlay>를 먼저 열어 보세요. 이 주소도 안 열리면 `start.bat` 명령 창이 실행 중인지 확인하면 됩니다.

## 대회와 라운드 관리

제어 화면에서 다음 항목을 대회별로 저장할 수 있습니다.

- 대회 이름
- 8개 팀 이름
- 점수판 제목
- 파스텔 핑크·브라운·그린·블루·레드 템플릿
- `+` 버튼으로 여는 텍스트·KS·순위·전멸 효과 세부 색상

미리보기 아래의 라운드 현황에서 팀별 상태(`ACTIVE`, `BREAK`, `TERMINATED`, `ESCAPE`)와 KS·TS·패널티를 수정할 수 있습니다. `TERMINATED`는 오버레이의 기존 `ELIMINATED` 상태로 반영됩니다. 잘못 저장했다면 마지막 수정 되돌리기를 눌러 해당 라운드에서 마지막으로 저장한 상태·점수 수정을 함께 취소할 수 있습니다. 패널티는 총 TS에 반영되지만 OBS 리더보드에 별도 열로 표시되지는 않습니다.

TS가 같으면 KS가 높은 팀이 위에 표시됩니다. KS도 같으면 해당 라운드에서 더 오래 생존한 팀이 위에 표시됩니다.

## 전멸 판정

- 선수 초상화의 사망·다운 상태를 개별 판정합니다.
- 초상화에 부활 시간초가 있으면 부활 대기 상태로 처리합니다.
- 1일차 전원 사망은 `BREAK` 상태로 유지합니다.
- 2일차 이후 생존자가 0명이고 부활 시간초도 없을 때 `ELIMINATED`로 확정합니다.
- 전멸 상태는 해당 라운드가 끝날 때까지 유지됩니다.

## 잘 안 될 때

### Python 설치 안내가 반복되는 경우

Python 3.10 이상을 다시 설치하면서 `Add python.exe to PATH`를 체크해 주세요. 설치가 끝나면 열려 있던 안내 창을 닫고 `start.bat`을 다시 실행합니다.

### 처음 실행이 오래 걸리는 경우

첫 실행에만 필요한 Python 파일을 받습니다. 인터넷 연결을 확인하고 검은 창을 닫지 않은 채 기다려 주세요.

### OBS에서 오버레이가 비어 있는 경우

- `start.bat` 명령 창이 열려 있는지 확인합니다.
- 브라우저 소스 URL이 `http://127.0.0.1:8765/overlay`인지 확인합니다.
- 브라우저 소스 크기를 800×600으로 맞춥니다.
- OBS 브라우저 소스를 새로고침합니다.

### 게임 화면을 찾지 못하는 경우

- 이터널 리턴을 먼저 실행한 뒤 제어 화면을 새로고침합니다.
- 게임을 창 모드 또는 테두리 없는 창 모드로 실행합니다.
- 게임 해상도와 관전자 HUD가 1920×1080인지 확인합니다.

## 설정과 개인정보

프로그램은 `127.0.0.1`에서만 돌아갑니다. 게임 화면이나 점수를 외부 서버로 보내지 않습니다. EXE 버전은 Windows 사용자 설정에 저장하고, 소스 코드 버전은 프로그램 폴더의 `config.json`에 저장합니다.

프로그램을 삭제하려면 실행 중인 명령 창을 닫고 EXE 파일을 삭제하면 됩니다. 소스 코드 버전의 설정을 보관하려면 삭제 전에 `config.json`을 따로 복사하세요.

## 개발 및 기여

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

## 현재 인식 범위

현재는 1920×1080 이터널 리턴 관전자 HUD를 기준으로 맞춰 놨습니다. 게임 업데이트로 HUD 위치나 배율이 바뀌면 인식 좌표나 숫자 템플릿도 다시 맞춰야 할 수 있습니다.

이 프로젝트는 비공식 커뮤니티 도구이며 Nimble Neuron 및 게임 공식 운영사와 제휴하거나 보증받지 않았습니다.
